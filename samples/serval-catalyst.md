# Catalyst documentation for Serval

Serval is an LLM-based IT administration platform. Catalyst is its admin-facing agent, which builds workflows, skills, dashboards and journeys, and investigates issues. I drafted and published the Catalyst docs from scratch as docs-as-code, using Mintlify and Claude Code. The set covers an overview, getting started, a tutorial, and guides to workflows, dashboards and access management. I verified every claim by hand against the codebase before publishing.

- [Catalyst overview](https://docs.serval.com/sections/documentation/catalyst/overview)
- [Tutorial: Build automations from ticket history](https://docs.serval.com/sections/documentation/catalyst/tutorial)
